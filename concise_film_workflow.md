# ChipTech Concise Workshop Film: Electrical Logic

## Story objective

The 15-second entry film demonstrates a compact, plausible first breadboard test. It does not pretend to manufacture a circuit, solder a breadboard, or conjure an autonomous robot. Nim and Pip assemble a **microcontroller-controlled LED test**: a microcontroller development board connects to a breadboard containing an LED and a current-limiting resistor, then a simple push switch changes the observable LED state. The final composition signals that practical work becomes collaborative.

## Technical topology

| Element | Physical role in the miniature set | Electrical role |
|---|---|---|
| Microcontroller development board | Sits beside the breadboard, never inserted into it | Supplies a digital output, 3.3 V, and ground through jumper wires |
| Breadboard | Central build surface | Holds the LED, resistor, and tactile switch in separate rows |
| Red jumper | Runs from the development board’s 3.3 V pin to the positive rail | Provides supply to the tactile switch |
| Black jumper | Runs from board ground to the ground rail | Establishes the return path |
| Cyan jumper | Runs from board digital output to the 220 Ω resistor and then LED anode | Carries the controlled output signal |
| LED cathode lead | Reaches the ground rail | Completes the LED return path |
| Tactile switch | Bridges the positive rail to an input jumper | Demonstrates a test input, not a magical power source |

The visual sequence deliberately shows only the relationship that matters: source and ground connect first, a controlled LED path completes second, and the physical switch produces one clear test result third. No claim is made that the figures write code inside the film.

## Global visual and sound definition

The fixed upright 16:9 camera looks slightly down at a miniature graphite workbench. Nim remains a cocoa-brown wool-felt oval with an off-white face panel, black button eyes, charcoal legs, and a stitched cyan thread. Pip remains an amber clay pebble with copper-wire square glasses and wheel feet. The visible workbench uses only the pre-established palette: graphite, off-white paper, cyan signal wire, restrained amber power cue, and copper construction wire. The clips are original practical stop-motion with no text, labels, logos, narration, dialogue, or music. The only audio is restrained workshop Foley.

## Continuity rule

Each clip begins with the actual final frame of the previous clip. The development board, breadboard, LED, resistor, switch, three jumpers, Nim, and Pip remain physically visible once introduced. The camera does not pan, zoom, or change angle. The last second of the third clip is held steady for entry into the homepage.
